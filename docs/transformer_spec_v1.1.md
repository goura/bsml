# BSML Transformer Specification v1.1

## 1. Overview
The Transformer layer is a pure, side-effect-free module. It takes the `BSMLDocument` (AST) generated by the Parser and converts it into a flat array of `nodes` and `edges` compatible with React Flow (`@xyflow/react`).

It handles all heavy calculations:
1. **Global Scale Calculation** (with Zero-Division guards)
2. **Auto-balancing** (Padding / Imbalance detection)
3. **Handle ID resolution for Edges** (including implicit edges for callouts and collision prevention)

## 2. Transformer Output Types (React Flow Data Payload)

The Transformer MUST output an object containing React Flow nodes and edges. We define specific generic data types for our custom nodes.

```typescript
import { Node, Edge } from '@xyflow/react';
import { BalanceSheetNode, NoteNode, CalloutNode } from './ast_types';

export interface BSMLReactFlowData {
    nodes: Node[];
    edges: Edge[];
}

// ---------------------------------------------------------
// Custom Node Data Payloads
// ---------------------------------------------------------

// Payload for 'balanceSheet' custom node
export interface BalanceSheetNodeData {
    ast: BalanceSheetNode; // The original AST node
    scaleFactor: number;   // Pixels per 1 amount unit
    totalHeight: number;   // Expected total height of the node in pixels
    padding?: {
        side: 'assets' | 'liabilities_equity';
        type: 'imbalance' | 'rounding';
        amount: number;
    };
}

// Payload for 'note' custom node
export interface NoteNodeData {
    ast: NoteNode;         // The original AST node (for future-proofing)
    text: string;
}

// Payload for 'callout' custom node
export interface CalloutNodeData {
    ast: CalloutNode;      // The original AST node (for future-proofing)
    sourceAlias: string;
    pieData: Record<string, number>;
}
```

## 3. Transformation Algorithms (Critical for AntiGravity)

AntiGravity MUST implement the `transform(ast: BSMLDocument, maxNodeHeight = 600): BSMLReactFlowData` function following these strict rules:

### 3.1 Total Calculation & Balancing
For every `BalanceSheetNode` in the AST:
1. Recursively calculate `totalAssets` by summing all `amount` fields inside the leaf `ItemNode`s of the `assets` tree. (Safe from double-counting as groups have no amounts).
2. Recursively calculate `totalLiabilitiesAndEquity` by summing all `amount` fields inside the leaf `ItemNode`s of the `liabilities` and `equity` trees.
3. Determine `maxSideValue = Math.max(totalAssets, totalLiabilitiesAndEquity)`.
4. Calculate `difference = Math.abs(totalAssets - totalLiabilitiesAndEquity)`.
5. If `difference > config.tolerance`:
   - Inject a `padding` object into the `BalanceSheetNodeData`.
   - `side` is the side with the smaller total.
   - `type` is `'imbalance'`.
   - `amount` is `difference`.
6. If `0 < difference <= config.tolerance`:
   - Inject a `padding` object. `type` is `'rounding'`.

### 3.2 Global Scaling
1. Find the absolute maximum `maxSideValue` across ALL Balance Sheets in the AST. Let's call this `globalMaxAmount`.
2. **Zero-Division Guard:** `if (globalMaxAmount === 0 || Number.isNaN(globalMaxAmount)) { scaleFactor = 0; }`
3. Else: `scaleFactor = maxNodeHeight / globalMaxAmount`.

### 3.3 Node Generation
Generate React Flow `Node` objects:
- **BalanceSheet Nodes:** `id` = `ast.id`, `type` = `'balanceSheet'`, `data` = `BalanceSheetNodeData`.
- **Note Nodes:** `id` = `ast.id`, `type` = `'note'`, `data` = `NoteNodeData`.
- **Callout Nodes:** `id` = `callout-${ast.source.bsId}-${ast.source.alias}`, `type` = `'callout'`, `data` = `CalloutNodeData`.

**Height calculation for BalanceSheet nodes:**
```
assetsColumnHeight    = renderedAssetsHeight + paddingHeight(assets side) + MIN_ROW_HEIGHT          // 1 subtotal row
liabEqColumnHeight   = renderedLiabEqHeight  + paddingHeight(liabEq side) + MIN_ROW_HEIGHT * 3 + BS_HEADER_HEIGHT
//                                                                            ^^^^^^^^^^^^^^^^   ^^^^^^^^^^^^^^^^
//                                                                            3 subtotal rows    Equity header row
totalHeight          = max(assetsColumnHeight, liabEqColumnHeight)
calculatedHeight     = totalHeight + BS_HEADER_HEIGHT   // the top Assets/Liabilities header band
```

### 3.4 Edge & Handle Generation
React Flow needs exact `sourceHandle` and `targetHandle` strings.

**Explicit Edges (from AST `edges`):**
For every `EdgeNode` in the AST (iterate with index `i`):
- `id` = `edge-${source.nodeId}-${source.alias || 'root'}-to-${target.nodeId}-${target.alias || 'root'}-index-${i}`  *(Collision prevention)*
- `source` = `source.nodeId`
- `target` = `target.nodeId`
- `sourceHandle` = If `source.alias` exists, `handle-${source.nodeId}-${source.alias}`. Else `undefined`.
- `targetHandle` = If `target.alias` exists, `handle-${target.nodeId}-${target.alias}`. Else `undefined`.
- `label` = `edge.label` (if any).
- `animated` = true (if `style === 'dotted'`).
- `style` = `{ strokeDasharray: '5,5' }` (if `style === 'dotted'`).

**Implicit Edges (for Callouts):**
For every `CalloutNode` in the AST (iterate with index `j`):
- `id` = `edge-callout-${ast.source.bsId}-${ast.source.alias}-index-${j}`
- `source` = `ast.source.bsId`
- `sourceHandle` = `handle-${ast.source.bsId}-${ast.source.alias}`
- `target` = `callout-${ast.source.bsId}-${ast.source.alias}` // Points to the generated Callout Node
- `animated` = false
- `style` = `{ stroke: '#94a3b8' }` // Neutral connecting line
